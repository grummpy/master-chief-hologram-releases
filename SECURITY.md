# Security

Report a vulnerability privately through GitHub Security Advisories for this repository. Do not place credentials, private prompts, personal documents, generated private media, LAN addresses, or exploit details in a public issue.

Master Chief is local-first, but configured cloud providers receive the command only when selected. Tool approvals are enforced in the Electron main process. New application-owned content controls or filters require the repository owner's exact prior approval under `AGENTS.md`.

Supported local release: the current `main` branch and most recent Desktop build. Public redistribution remains blocked until an authorized Developer ID signing and notarization workflow exists.
