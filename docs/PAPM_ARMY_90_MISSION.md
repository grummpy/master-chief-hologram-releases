# PAPM Army 90 Mission

Mission run: `MC-ARMY-90-20260920`

## Objective

Independently assess and improve every applicable non-release capability of Master Chief Hologram v1.41.0 until each specialist lane reaches at least 90/100 on a frozen, evidence-based rubric, or returns a documented blocker. Produce a final path-to-100 report covering every routed member.

## Users and decisive journeys

1. Ask a natural-language question, steer the answer, and receive accurate, recoverable output.
2. Ask for an Excel, Word, PowerPoint, or code file and immediately find, open, save, revise, and preserve it.
3. Use Git, local tools, MCP, attachments, research, and local models without hidden dead ends.
4. Clear private conversation/media traces while preserving deliberately saved projects and credentials.
5. Operate Ollama, Hugging Face routes, Qwen/Dolphin families, and ComfyUI with explicit readiness and recovery evidence.

## Frozen scoring model

Each lane scores 100 total points: functional completeness 30, failure handling 15, usability/accessibility 15, privacy/security/legal fit 15, verification depth 15, documentation/operability 10. A lane passes at 90 only with observable evidence. No release signing/notarization work is in scope.

## Roster and work packages

- Engineering/model lane: Jarvis, Local Model Operations, Signals Officer, Chief Operations, Prompt Engineering, Fleet Engineer.
- UX/artifact/publishing lane: Chief UX, Productivity Artifact Engineer, PowerPoint SME, Warrant Officer Data, Archivist, Public Affairs Officer.
- Legal/privacy/safety lane: Staff Judge Advocate, Safety Officer, Sergeant Major Security, AI Governance, Training Officer.
- Reconciliation and independent verification: Master Chief, PAPM, Captain Intelligence, Lieutenant Quality, Test Pilot.

## Gates

- Plan gate: scope, scoring, journeys, owners, exclusions, and evidence paths complete.
- Implementation gate: code changes preserve unrelated work and app-owned content-control changes remain outside scope without direct approval.
- Product gate: all deterministic tests pass, production dependency audit is clean, installed bundle opens, and each lane either scores at least 90 or names the exact blocker.
- Final gate: `docs/ARMY_PATH_TO_100_FINAL.md` contains every routed member, score, evidence, residual gap, and ordered path to 100.

## Risks and constraints

- A static string test cannot substitute for a runtime journey.
- Provider/model behavior is not application behavior; both must be scored separately.
- Legal review is issue-spotting and licensing/privacy analysis, not legal advice.
- Publishing means artifact/stakeholder readiness, not public deployment.
- Do not weaken a rubric after seeing results or credit unavailable external evidence.
