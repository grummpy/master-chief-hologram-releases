# Original Holographic Command Companion — Visual Style Brief

Version 1.0 · 2026-09-13 · G0 graphics foundation · Review status: ready for owner approval

## Creative direction

The product presents an original holographic command companion: a dark-navy naval officer or abstract command silhouette, cyan projection light, restrained scanlines, and an approachable professional stance. The compose panel and system status remain visually primary; the figure provides atmosphere and state reinforcement.

Do not use Halo or other franchise logos, names, insignia, green sci-fi armor, military helmets/visors associated with an existing character, weapons, game screenshots, fan art, copied audio, or claims of affiliation. Every generated or commissioned request must include: **“Original holographic command companion; do not reference or reproduce any existing game or franchise character.”**

## State taxonomy

| State | Meaning | Text status | Non-color cue | Reduced-motion behavior |
|---|---|---|---|---|
| Idle | Waiting | Standing by | Neutral upright pose | Static still |
| Ready | Input focused / available | Ready for orders | Open posture or brighter projection ring | Static still |
| Listening | Microphone capture | Listening | Visible sound-wave / listening badge | Static badge, no pulse |
| Thinking | Request in progress | Analyzing command | Downward gaze / data-grid motif | Static grid |
| Speaking | Response is arriving | Reporting | Forward gesture / speech marker | Static pose |
| Success | Completed | Mission complete | Check marker / upright salute | Static check marker |
| Attention | Error or recovery required | Action needed | Alert marker / distinct posture | Static alert marker |

The existing text labels in the renderer are the accessibility source of truth. Artwork may reinforce a state but may never be the only cue.

## Icon-size review

Review the approved icon at 16, 32, 64, and 128 pixels on light and dark Finder backgrounds. It must retain a unique cyan holographic silhouette, avoid text-dependent detail, show no trademarked symbol, and remain distinguishable from a generic document or game icon. Record reviewer, screen scale, result, and the approved source hash in [ART_PROVENANCE.md](ART_PROVENANCE.md).
