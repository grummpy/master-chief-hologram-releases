# Master Chief hologram assets

- `drive/original_mascot.png`: **official Grok-designed chibi navy Master Chief** mascot (deep navy + gold, glowing cyan eyes). Canonical identity for the skill and this app.
- `icon.png`: Desktop / Dock / tray icon — square crop of the Grok mascot (updated 2026-09-12).
- `master-chief-hologram-v1.png`: alternate holographic officer still (OpenAI image tool, 2026-09-12). Kept as secondary/reference; runtime state art under `states/` is preferred for expressions.
- `hologram-placeholder.svg`: deterministic recovery asset if generated stills cannot load.
- `states/`: day/night expression stills used by the interactive hologram stage.

An optional future idle animation may be supplied as `hologram-idle.mp4`. The interface animates state stills when no video is installed.
